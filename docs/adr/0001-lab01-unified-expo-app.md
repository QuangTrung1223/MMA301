# Unified Expo JavaScript App with In-App Tab Switcher for Lab01

For Lab 1 of MMA301, we evaluated whether to create separate projects for the Layout assignment (LoginScreen and ShoppingCartScreen) and the Task Manager assignment (Todo List), or unify them. We decided to create a single Expo JavaScript application in the `Lab01/` directory using an in-app state-based tab switcher. This avoids multi-project overhead, keeps dependencies lightweight for first-week students, and allows professors to evaluate all three required screens in one running instance.
